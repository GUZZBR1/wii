## Itens verificados que não pedem nova infraestrutura

- Não existe API de servidor, autenticação ou armazenamento remoto do produto. Não criar camadas de API/repositório ou permissões próprias sem necessidade de produto.
- O workspace de `@wii/spatial-core`, seu build para `dist` nos testes e o alias Vite para fonte no app têm papéis diferentes; a auditoria atual não encontrou duplicação que justifique removê-los.
- Os testes `cameraPip.test.ts` e `cameraPip.test.tsx` verificam contratos diferentes (markup e estado DOM/interação); não são uma duplicação comprovada.
- Worktrees com alterações locais foram inspecionadas em modo somente leitura. Nenhuma implementação incompleta foi copiada para esta branch.
